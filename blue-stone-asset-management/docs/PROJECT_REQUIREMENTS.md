# Blue Stone Asset Management - Project Requirements

## Overview
This project will deliver a modern asset management website inspired by the BlackRock brand aesthetic, with a clean corporate layout, refined typography, and a muted dark/blue color palette.

The application will target institutional and retail investors, with a seamless customer experience for registration, dashboard access, portfolio tracking, and market news.

## Goals
- Create a professional digital presence for Blue Stone Asset Management.
- Enable user signup, login, password recovery, and investor dashboard access.
- Allow users to monitor investment performance, allocation, and wallet balances.
- Provide rich content and corporate navigation based on financial services conventions.
- Follow disciplined front-end engineering practices, including Airbnb-style linting, TypeScript, and Next.js best practices.

## Primary Navigation
The main site must include the following top-level sections:
- About Us
- Newsroom
- Insights
- Investor Relations
- Corporate Sustainability
- Careers

## Core User Journeys
### 1. New User
- Access homepage and review company positioning.
- Navigate to signup flow.
- Complete registration and verify account.
- Land on a personalized investor dashboard.

### 2. Returning User
- Access login screen.
- Authenticate securely.
- Access dashboard showing current portfolio performance and wallet state.

### 3. Password Recovery
- Visit "Forgot Password" from login.
- Enter email address.
- Receive reset instructions.
- Complete reset flow and return to login.

## User Dashboard
The dashboard must show:
- Investment performance summary.
- Asset allocation by sector.
- Portfolio positions across product categories: gold, silver, ETF, crypto.
- Deposit and withdrawal actions.
- Wallet balance and transaction summary.
- Daily market updates and newsletter signups.
- CEO letters and shareholder communications.

## Investment Product Experience
Provide UI support for:
- Gold investments
- Silver investments
- ETF investments
- Crypto investments
- Option to deposit funds
- Option to withdraw currency
- Wallet management and transaction summary

## Content & Engagement
- Daily market updates
- Newsroom articles and press releases
- Insights and research content
- Investor relations announcements
- Corporate sustainability messaging
- Career opportunities
- CEO letters to shareholders

## Theming Inspiration
Use BlackRock-inspired theming:
- Crisp, restrained layout
- Dark navy / charcoal / cool blue palette
- Subtle contrast and refined typography
- Minimalistic dashboards with professional financial chart styling
- Clear, corporate navigation and page hierarchy

## Non-functional Requirements
- Responsive layout for desktop, tablet, and mobile.
- Accessible contrast and semantic HTML.
- Secure authentication patterns.
- Clean code and consistent naming.
- Strong typing using TypeScript.
- Production-ready Next.js app.
- SEO-friendly page metadata.
- Server-side rendering for SEO-critical pages and metadata delivery.
- Core Web Vitals scores above 90 for performance, accessibility, and best practices.
- WCAG 2.1 AA compliance for accessibility.
